# Minecraft Survivors 2 — план улучшений глав I–III

База: копия 0.11.0 из `~/MinecraftSurvival` (оригинал не трогается).
Стартовое состояние: git-репозиторий, `scripts/verify.sh` полностью зелёный
(все headless-тесты и ~2500 проверок ассетов).

Правила работы:
- Все решения из `AGENTS.md` остаются в силе (лаконичный UI, без кругов радиусов,
  размер ЭндерСтива, голые стволы, без выбора стартового оружия и т. д.),
  пока ты сам не скажешь иначе.
- Каждый этап — отдельные коммиты, `verify.sh` зелёный, скриншоты «до/после».
- После каждого этапа — остановка и показ тебе. Дальше иду только с твоего «ок».

## Этап 1. Архитектура (игра внешне не меняется)

**1.1 Страховочная сетка.** Тест детерминизма: автоигрок проходит каждую главу
с фиксированным seed, в контрольных точках снимается хеш состояния мира
(HP, позиции, мобы, RNG). Рефакторинг обязан давать побайтно тот же хеш —
так гарантируется, что баланс и поведение не поплыли.

**1.2 Разбор `main.gd` (81 КБ, 81 функция, 150+ draw-вызовов).**
- `screen_router.gd` — стек экранов вместо `pause_from / stats_from /
  inventory_from / achievements_from / lab_screen`: «вернуться» = pop, без
  ручного запоминания, откуда пришли.
- `screens/` — меню, выбор главы, настройки, пауза, инвентарь, рецепты,
  выбор уровня, сундук, результат, достижения, мультиплеер: по файлу на экран.
- `hud.gd`, `world_view.gd` (мир, актёры, снаряды, эффекты).
- `qa_harness.gd` — весь `qa_mode`, автоигрок, запись видео и стресс-режим
  уходят из боевого кода.

**1.3 Главы через композицию, а не цепочку наследования.**
Сейчас `end_world → nether_world → campaign_world → world`: Край наследует
весь Незер (пиглинов, песок душ, кувшины), и любая правка Незера может
сломать Край. Новая схема:
- `campaign_world.gd` — общие одиночные правила;
- системы-модули: инвентарь и рецепты, статус-эффекты (огонь, иссушение,
  яд, левитация), лут-контейнеры, расширенное оружие;
- `chapters/overworld.gd`, `nether.gd`, `end.gd` — описание главы: пул оружия,
  баланс, рельеф, арена, сценарий босса, рендерер.
Это же подготовка к главе IV: новая глава = новый файл описания, а не ещё одно
звено цепочки.

**1.4 Числа в данные.** Магические константы боя и боссов из кода
переезжают в `data/*_balance.json` — баланс можно крутить без правки GDScript.

Кооп (правила 0.6.1) не меняю, только перевожу на те же модули без изменения
протокола; сетевые тесты должны остаться зелёными.

## Этап 2. Графика (только визуальный слой, симуляция/хитбоксы/RNG не меняются)

**Общее для всех глав**
- Световой проход (совместим с Compatibility-рендером): карта освещения
  с источниками — факелы, огонь, лава, снаряды, взрывы, кристаллы, порталы.
  Мир затемняется, источники реально светят.
- Тени у всех актёров, пропов и снарядов; у прыжка, элитр, дракона и
  левитации тень отрывается от тела по высоте.
- «Сочность» попаданий: белая вспышка моба на 1–2 кадра, лёгкий отброс
  спрайта, хит-стоп на крупных ударах, след у сфер опыта, вспышка при
  повышении уровня, виньетка при низком HP. Всё уважает настройки «Тряска» и
  «Вспышки».
- Камера с упреждением по направлению движения.

**Глава I — Верхний мир «До рассвета»**
- Ночь, которая за 12 минут идёт к рассвету: темнее к середине, на финале —
  первая полоса зари (ровно под название игры).
- Вариативная трава, цветы и высокая трава, качающиеся от движения; светлячки,
  туман по низинам, лунные блики на воде.

**Глава II — Незер**
- Пульсирующее свечение лавы с реальным светом на округу, пепел и искры
  в воздухе, дрожание воздуха над лавой, багровый туман по краям экрана.
- Песок душ с синими огоньками душ.

**Глава III — Край**
- Пропасти перестают быть чёрными дырами: обрывы острова получают боковые
  стенки из эндерняка, уходящие в бездну, внизу — звёздное небо с параллаксом
  и пурпурной дымкой.
- Частицы эндермена и портала, мерцание кристаллов с лучами к дракону
  (сейчас связь видна плохо).

## Этап 3. Контент (в рамках текущих правил и наград)

**Глава I**
- События ночи на таймере: 3:00 — туман и волна зомби с факелами,
  6:00 — «кровавая луна» (плотный спавн, больше опыта), 9:00 — фантомы,
  пикирующие сверху (с предупреждением-тенью).
- Ориентиры на карте: разрушенная деревня с сундуком, пруд, шахтный вход —
  чтобы мир не был однородным полем.
- Ведьма: зелья по площади с предупреждением, лечит соседних мобов —
  приоритетная цель.

**Глава II**
- Зоны с разными правилами: багровый лес (хоглины), долина душ (уже есть
  песок душ — добавятся скелеты и синий огонь), базальтовые дельты
  (магмовые кубы, узкие проходы).
- Мини-событие на середине: штурм бастиона — отбиться от волны пиглинов
  у сундука ради гарантированной эволюции.
- Ифриты: стационарные турели по краям, сбиваются любым оружием.

**Глава III**
- Шалкеры у руин: снаряды с самонаведением, попадание даёт короткую
  левитацию (механика левитации уже есть в коде).
- Руины города Края с охраняемым сундуком и редкой наградой.
- Эндермиты из брошенного жемчуга, событие «бездна зовёт» — порывы,
  сносящие к краю (с визуальным предупреждением).

**Общее**
- Экран итогов забега: урон по каждому оружию, лучший момент, время глав.
- +6 достижений под новый контент (в стиле существующей книги).
