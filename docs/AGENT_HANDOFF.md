## Мобы и Стив: как сделаны сейчас

Это собственные 2D-спрайты, а не извлечённые ванильные скины.

1. Встроенный imagegen подготовил индивидуальные опорные изображения по
   официальным референсам. Полные запросы и описания каждого существа:
   [ASSET_PROMPTS.md](ASSET_PROMPTS.md).
2. Исходники сохранены в `assets/art_source/`. `*_anchor.png` — down,
   `*_up.png` — вид сзади, `*_side.png` — правый бок. Всего семь персонажей.
3. `scripts/assemble_sprites.py` нормализует изображения, извлекает голову
   и корпус, строит конечности и запекает позы собственным 2D-ригом.
   Атласы целиком imagegen не генерировал; обновление анимаций 0.2 сделано
   без новых вызовов генерации.
4. Атлас имеет три строки `down / up / side`, 22 столбца: idle 4, walk 8,
   windup 3, attack 2, recover 3, hurt 2. Левый бок зеркалится в игре.
5. Размеры: гуманоиды/крипер/слизень 32×32, паук 48×32, разоритель 64×64.
   Опоры и длительности: `data/animations.json`, `docs/ASSET_MANIFEST.json`.
6. Элита использует опоры зомби, броню рига и масштаб 1,25; маленький
   слизень — тот же атлас с масштабом 1/2. Во время движения и действия
   `main.gd` может объединять верх текущей позы с ногами шага.

```sh
python scripts/assemble_sprites.py --only steve zombie creeper
python scripts/assemble_sprites.py
python scripts/check_atlases.py
```

Повторный imagegen по тому же запросу не обязан дать тот же результат.
Воспроизводимость обеспечивают **сохранённые PNG** и сборщик.
В риге есть вручную заданные цвета конечностей и геометрия: подмена только
голов/корпусов не сделает весь персонаж ванильным.

Для будущей замены мобов развёртки `textures/entity/*.png` нельзя считать
готовыми спрайтами. Нужны модели с правильными UV, проекция и кадры направлений
и анимаций. Сохраняйте читаемый силуэт, точки опоры, моменты контакта атак и
коллизии; отдельно учитывайте прозрачность слизня и броню элиты.

На момент проверки 1.21.11 — самая новая установленная релизная версия с
доступным JAR; найдена в экземплярах `1.21.11` и `1.21.11(1)`. Это факт о
локальной установке, а не о последнем релизе в интернете.

`scripts/import_minecraft_assets.py` находит версии экземпляров и извлекает
нужные ресурсы; аккаунты лаунчера не читает. Охвачены все 18 предметов игры.
Обычные иконки и стадии лука скопированы побайтово. Зелья собраны из слоёв
с цветом отравления `#87a363`. Сундук и клыки — проекции текстур моделей в 2D.
Блеск зачарования, огонь, частицы, взмах, взрыв и опыт используют ванильные
ресурсы. Огонь сохраняет `.mcmeta`: 16…31, затем 0…15, 20 кадров/с.
Окружение использует оригинальные текстуры блоков и 2D-проекции.

```sh
python scripts/import_minecraft_assets.py
# параметры: --prism /путь/к/PrismLauncher или --jar /путь/к/client.jar
python scripts/check_minecraft_assets.py
```

`assets/minecraft/` — исходники, `assets/sprites/` — готовые PNG.
Источники и SHA-256: `docs/MINECRAFT_ASSET_MANIFEST.json`.
Клипы: `data/minecraft_assets.json`. Подробности:
[MINECRAFT_TEXTURES.md](MINECRAFT_TEXTURES.md).
`scripts/make_assets.py` теперь вызывает импорт, а не старый генератор иконок.

## Музыка, звуки, шрифт и HUD

`scripts/import_minecraft_presentation.py`:

- Находит звуки через `assets/indexes/29.json` в хранилище Prism
  `assets/objects/<два символа SHA-1>/<SHA-1>`. Проверяет SHA-1 и копирует
  оригинальные OGG без перекодирования: 67 файлов, 26 событий.
- Берёт музыку из `/home/daydert/Downloads/Telegram Desktop/MusicForGame.mp3`.
  Внутри AAC, поэтому ffmpeg готовит `assets/audio/music.ogg`, Vorbis q6.
  Полный трек 320,04 с зациклен; исходник пользователя не изменён.
- Готовит BMFont из оригинальных bitmap-провайдеров `ascii`,
  `nonlatin_european`, `accented`: 2414 символов с кириллицей.
  Файлы: `assets/fonts/minecraft/`. Bold повторяет смещение на один пиксель.
- Извлекает сердца, опыт, выделение слота и кнопки. Хотбар адаптирован
  к двум независимым группам по шесть слотов в нижней линии.

```sh
python scripts/import_minecraft_presentation.py
# параметры: --prism /путь/к/PrismLauncher --music /путь/к/треку
python scripts/check_presentation_assets.py
```

Синтезированные WAV удалены. `scripts/make_audio.py` теперь запускает импорт.
Для подготовки нужны Pillow и ffmpeg; графике предметов также нужен NumPy.
Готовой игре Python, ffmpeg и установленный Minecraft не нужны.

Происхождение: `docs/MINECRAFT_PRESENTATION_MANIFEST.json`,
`licenses/PROJECT_NOTICE.md`; подробности —
[PRESENTATION_UPDATE.md](PRESENTATION_UPDATE.md).
Оформление и метрики: `DESIGN.md`, `.impeccable/design.json`.

## Что важно сохранить

- L работает физической клавишей и в русской раскладке. Чёрные характеристики
  закрываются L / Esc / «Готово» с возвратом точного состояния: RUNNING,
  PAUSED, LEVEL_UP или CHEST. Числа берутся из формул баланса.
- Пауза, выбор улучшения и характеристики останавливают игровые часы и
  анимации; музыка продолжает играть.
- Звуки используют отдельный RNG. Визуальные изменения не должны менять
  урон, перезарядки, добычу, коллизии и случайные числа боя.
- Шесть оружий, шесть пассивных, три эволюции, забег 720 с.
- Исходные ресурсы Mojang/Microsoft и собственный код имеют разное
  происхождение; лицензия кода не распространяется автоматически на ресурсы.

## Проверка и поставка

```sh
./scripts/verify.sh
./scripts/verify.sh --visual
./.tools/Godot_v4.7.2-stable_linux.x86_64 --headless --path . -s qa/compare_combat.gd
./scripts/build.sh
python scripts/package.py
```

Визуальные проверки используют Linux/Wayland. Для чистой проверки импорта
используйте копию без `.godot` и `.import`; исходные ресурсы сохраняйте.
На завершении 0.4 прошли 845 основных проверок, 21 проверка презентации и
визуальные проверки анимаций/предметов; 5400 шагов боя совпали с фикстурой
исходной симуляции. Linux-бинарник запускался из `/tmp`. Windows экспортирован
официальным шаблоном, нативный запуск Windows здесь не проверялся. Эти
результаты относятся к завершённому обновлению, а не к будущим изменениям.

Готовые архивы: `builds/MinecraftSurvivors-{Linux-x64,Windows-x64,Source}.zip`.
Контрольные суммы: `builds/packages.json`, `builds/SHA256SUMS.txt`.
Отчёты и видео: `qa/`; последнее видео —
`qa/recordings/presentation_update.mp4`.
