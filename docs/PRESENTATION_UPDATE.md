# Обновление 0.4 — музыка, звуки и Minecraft HUD

Фоновая музыка заменена на предоставленный пользователем файл
`/home/daydert/Downloads/Telegram Desktop/MusicForGame.mp3`. Внутри файла AAC;
для Godot подготовлен `assets/audio/music.ogg` (Ogg Vorbis, quality 6). Сохранён
полный трек длительностью 320,04 с, включено повторение. Исходник пользователя
не изменён. Музыка и эффекты имеют отдельные настройки громкости.

Синтезированные WAV удалены из `assets/audio/`. Все эффекты теперь являются
оригинальными OGG Minecraft Java 1.21.11 из локального Prism Launcher, индекс
ресурсов 29. Используются **67 файлов и 26 игровых событий**: взмах, лук,
трезубец, огненный заряд, зелье, клыки, молния, взрыв, шипение, урон игрока,
урон разных мобов, опыт, уровень, подбор, сундук, разрушение и кнопки.
Файлы скопированы без перекодирования; SHA-1 проверен по индексу Minecraft.
Выбор вариантов использует отдельный RNG, а не случайные числа боя.
Ограничение 24 одновременных голосов и относительные уровни событий удерживают
звуки в пределах общей громкости. Изменение громкости действует и на уже
играющие звуки.

Интерфейс:

- Сердца 9×9 с шагом 8 пикселей, полусердца, пустые сердца и кадры мигания —
  исходные спрайты Minecraft. Здоровье расположено над нижними слотами.
- Шкала опыта и выделение слота используют оригинальные GUI-текстуры.
  Ванильная панель адаптирована к двум независимым группам по шесть слотов.
- Постоянная цветная верхняя плашка убрана. Текст белый/серый с чёрной
  пиксельной тенью; меню и кнопки серые. Красный цвет здоровья, зелёный опыта
  и исходные цвета предметов сохранены.
- Настоящие глифы Minecraft `ascii`, `nonlatin_european`, `accented` собраны
  в BMFont для Godot. Доступны 2414 символов, включая русский алфавит с Ё/ё.
  Используются целые масштабы 8/16/24/32; полужирное начертание повторяет
  однопиксельное смещение Minecraft. DejaVu в игровых сборках не используется.
- L (физическая клавиша, включая русскую раскладку) открывает характеристики
  на полностью чёрном фоне. L, Esc или кнопка «Готово» закрывают экран.
  Открытие также доступно в меню паузы.
- Экран показывает здоровье, скорость, бонус урона, снижение интервала,
  размер атак, защиту, радиус сбора, опыт, уровни и реальные параметры
  каждого оружия, пассивные предметы. Значения вычисляются из тех же
  формул, что и симуляция. Защита уменьшает входящий урон на 0,2 HP за
  уровень предмета и сохраняет минимум 1 HP урона.
- Характеристики останавливают бой и возвращают точное прежнее состояние:
  обычный бой, паузу, выбор улучшения или сундук. Пустой инвентарь поддержан.

Источники и контрольные суммы:
[MINECRAFT_PRESENTATION_MANIFEST.json](MINECRAFT_PRESENTATION_MANIFEST.json).
Повторная подготовка: `python scripts/import_minecraft_presentation.py`;
параметры `--prism` и `--music` позволяют задать другие локальные пути.

Проверки:

- `./scripts/verify.sh`: **845 проверок**, ошибок нет; из них 434 проверяют
  оригинальные байты звуков, GUI, глифы, музыкальный файл и покрытие событий.
- `qa/test_presentation.gd`: **21 проверка** реального воспроизведения,
  декодирования всех вариантов, полного трека и зацикливания, регулировки
  активных голосов, кириллицы, клавиши L, паузы, возврата состояний,
  формул и настоящего framebuffer 1280×720.
- `qa/compare_combat.gd`: **5400 шагов**, исходная симуляция совпадает во всех
  трёх сценариях; урон, коллизии, добыча и RNG не изменились.
- Чистая копия исходников импортирована без `.godot` и `.import`, код возврата 0.
- Linux-экспорт запущен из `/tmp`: ресурсы шрифта, музыки и GUI доступны
  внутри сборки, экран характеристик отрисован без ошибок загрузки.
- Windows x64 экспортирован официальным шаблоном; нативный запуск Windows
  в этой Linux-среде не проверялся.

Сняты меню, HUD, полные и пустые характеристики, улучшения, пауза, настройки,
результат и сундук; проверены логический размер 640×360 и настоящий кадр 2×.
Независимая визуальная проверка завершилась вердиктом **Ship**, без замечаний.
