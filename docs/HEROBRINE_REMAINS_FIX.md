# Тело после секретного финала главы I

Исправление поверх завершённой версии 0.9.0, изолированное от параллельной
разработки главы III. Общие `main.gd`, конфигурация, версии, баланс и новые
файлы Края не менялись.

Причины исчезновения: в фазе `vanish` отрисовка тела была пропущена, а затем
оставшийся старый спрайт почти полностью накрывали чёрная волна и затемнение.

Теперь после прохождения волны остаётся искривлённое тело Стива: сжатый торс,
повёрнутая голова, несимметрично вывернутые руки и ноги. Для него запечены
12 поз оседания из оригинальной текстуры Minecraft существующими
Importer/bake/part/transform. Новая поза не выпрямляется перед падением.

`herobrine_remains_view.gd` рисует тело поверх затемнения. При открытии портала
оно остаётся видимым; затем опускается, уменьшается и перекрывается поверхностью
портала снизу вверх. Скрывается после погружения. Слой относится только к
секретной ветке главы I и выключается в меню, при паузе, переходе к другой
главе и обычном поражении первой стадии. При возобновлении возвращается точный
кадр. Симуляция, урон, таймеры финала, музыка, RNG и кооп не менялись.

Изменены только существующие файлы:

- `scripts/herobrine_renderer.gd` — подключение изолированного слоя тела;
- `scripts/bake_herobrine_duel.py` — вызов дополнительного запекания при полной сборке.

Остальные файлы исправления новые. `main.gd` регистрировать ресурс не требуется:
приватный слой и PNG подключаются через `preload`. При сборке главы III они
попадут в готовую игру вместе с текущими исходниками. Происхождение ресурса:
`docs/MINECRAFT_REMAINS_MANIFEST.json`.

```sh
python scripts/bake_herobrine_remains.py
./.tools/Godot_v4.7.2-stable_linux.x86_64 --path . --display-driver wayland -s qa/test_herobrine_remains.gd
```

Проверены 11 условий: видимость после волны и над порталом, слой над шейдером,
неизменность RNG, остановка на паузе, точное возобновление, видимое погружение,
скрытие после падения, прежний финал, отсутствие тела в другой главе и сохранение
обычной ветки проигрыша. Результат: `qa/herobrine_remains_results.json`.

Проверочная сборка делается из последнего завершённого Source.zip с этими
файлами. Незавершённая глава III в неё не включается. Общие бинарники можно
заменить только при совпадении их отпечатков и общих файлов с началом задачи;
в ином случае используется отдельная сборка `builds/herobrine-remains-fix/`.
Windows экспортирован; нативная проверка выполняется для Linux.

## Обычная концовка — исправление поверх 0.10.1

При поражении в первой стадии затемнение комнаты накрывало обычную модель
Стива на 94%, а портал рисовался повторно поверх неё. Теперь прежняя поза
погибшего героя рисуется после затемнения и поверхности портала, перед плавным
появлением Незера. Стив виден при смерти, открытии портала и падении. Вращение,
уменьшение, затухание и длительность падения сохранены. Секретная ветка
по-прежнему использует отдельное искривлённое тело; кооп не изменён.

Из игрового кода изменён только `scripts/herobrine_renderer.gd`.
`qa/test_herobrine_remains.gd` теперь проверяет видимость обеих веток по пикселям
готового кадра. До исправления три проверки обычной ветки воспроизводили дефект;
после исправления все 17 условий проходят. Проверены также пауза, точное
возобновление и прежний переход в главу II. Кадры обычной ветки:
`qa/remains_ordinary_loss.png`, `qa/remains_ordinary_fall_start.png`,
`qa/remains_ordinary_fall_middle.png`.

Для этой правки обновляются обычные сборки Linux/Windows и стандартные архивы
текущей версии 0.10.1 со всеми тремя главами.
