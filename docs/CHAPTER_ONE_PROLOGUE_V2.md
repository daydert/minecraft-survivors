# Пролог I v2 — 3D-фильм (12 ноября 2026)

Сценарий пользователя: грядка → затмение → глаза Херобрина за Алекс → удар рукой насквозь →
остановка времени и реплика «Присоединишься к вечеринке после рассвета?» → распад Херобрина →
Алекс умирает на руках Стива → ярость → меч из сундука → уход в тёмный лес к мобам.

53 с, 1272 кадра, 24 fps, 1280×720, EEVEE, 20 сэмплов (~2,6 с/кадр).

## Файлы

- `scripts/cinematics/prepare_ch1_intro_v2.py` — локальные ванильные текстуры → `assets/art_source/ch1_intro_v2/`.
- `scripts/cinematics/build_ch1_intro_v2.py` — строит всю сцену (мир, риги, позы, камеры, свет, FX) и сохраняет
  `assets/art_source/ch1_intro_v2/ch1_intro_v2.blend`. ~15 с headless. Детерминирован: пересборка не меняет кадры,
  которых не касались правки.
- `scripts/cinematics/render_ch1_intro_v2.py` — рендер кадров в `qa/cinematics/ch1_intro_v2/frames/`
  (`--resume` пропускает готовые, `--start/--end` — диапазон, `--frames` — список).
- `scripts/cinematics/encode_ch1_intro_v2.py` — звук (лист событий в начале файла), субтитр, MP4
  `qa/recordings/chapter_one_prologue.mp4`, Theora `assets/cinematics/ch1_intro.ogv`, `ch1_intro_sfx.ogg`, постер.
- Игра: `scripts/chapter_one_prologue.gd` — фильм кончается в чёрное, затем `begin_intro(false)` (обычный вход из чёрного).

```sh
B=/home/daydert/.local/share/Steam/steamapps/common/Blender/blender
$B --background --factory-startup --python scripts/cinematics/build_ch1_intro_v2.py
$B --background assets/art_source/ch1_intro_v2/ch1_intro_v2.blend --python scripts/cinematics/render_ch1_intro_v2.py -- --samples 20 --start 985 --end 1272
python3 scripts/cinematics/encode_ch1_intro_v2.py
```

Проверка поз: `look` Blender MCP у Steam-Blender не отдаёт снимок (у контейнера свой /tmp), поэтому позы
проверялись headless-рендером Workbench с камеры шота / с боков.

## Не исправлено (замечания пользователя, 12.11)

Все правки в планах 41–53 с (кадры 985–1272); перерендерить только их, остальное не меняется.

1. **0:41 — слишком быстрый разворот на 180°.** В `pose_steve`, ветка `if t < 42.0` (поворот `yaw2` за 0,4 с
   внутри шота Rage). Решение: убрать поворот из кадра — Стив стоит до 42,0 с, план кончается на лице,
   склейка сразу к сундуку. Альтернатива — медленный поворот 1,2 с с переступанием (`locomote` на месте).
2. **0:43 — меч достаётся из деревянной части сундука; рука с мечом заходит в голову.** У сундука нет полости
   (корпус — сплошной `chest_body`). Решение: сделать корпус из стенок + тёмное дно внутри; ключи `rp` в шоте
   Sword (`t < 46.5`) опускать кисть ниже края (z≈.45 при стенке .625), меч показывать только когда кисть внутри;
   подъём вести по дуге в сторону (side −.35…−.45 от головы), полюс локтя наружу; проверить по виду сбоку.
3. **0:48 — Стив проходит сквозь сундук, затем сквозь забор.** Путь `locomote(... p0=SWORD_STAND, p1=V(-.6, 9.5))`
   идёт прямо. Решение: путь из нескольких отрезков — сначала шаг влево в обход сундука (x≈-3.4), затем к проходу
   в заборе (x∈[-1,0], y=5,2), затем в лес; проверить по виду сверху, что сундук/сено/столбы не пересекаются.
   `locomote` сейчас умеет только прямой отрезок — нужна версия по ломаной (длина по дуге → точка/направление).

Также можно чуть подсветить Стива в последнем плане (он почти силуэт).
