# Пролог I: грядка, Алекс, Херобрин

Актуальный сюжет — сообщение пользователя 12 ноября 2026; оно заменяет
старый вариант подхода к лесу в CHAPTER_ONE_CINEMATIC_AGENT_PROMPT.md.
50 секунд, 24 кадра/с, отдельный Blender-исходник и встроенный предрендер.

Стив хочет сохранить простой мир рядом с Алекс. Херобрин одним действием
разрушает его и оставляет приглашение. Стив сначала пытается спасти Алекс,
затем выбирает преследование. Херобрин не суетится: взгляд опережает движение,
устойчивая опора, короткий выпад, спокойное извлечение руки и исчезновение.

| Время | План и действие |
|---|---|
| 0–5 | Общий грядки у дома; Алекс собирает пшеницу, Стив помогает |
| 5–9 | Средний парный; обмен вниманием и лёгкий дружеский жест |
| 9–12 | Небо содрогается, свет гаснет; оба замечают перемену |
| 12–16 | За Алекс возникает Херобрин; она ещё смотрит на небо |
| 16–19 | Подготовка → сквозной удар рукой → запоздалая реакция |
| 19–22 | Стив срывается к Алекс, Херобрин встречает его взгляд |
| 22–26 | Херобрин улыбается: «Присоединишься к вечеринке после рассвета?» |
| 26–30 | Извлечение руки, исчезновение, потеря опоры Алекс, подхват |
| 30–36 | Стив опускается с Алекс на колено; голова и руки Алекс обмякают |
| 36–41 | Тишина; взгляд Стива от Алекс поднимается к тёмному лесу |
| 41–46 | Сундук, хват железного меча за рукоять, подъём |
| 46–50 | Стив уходит по тропе в лес; камера подготавливает игровую проходку |

Без изменения времени боя, RNG, HP, исходного меча I и финалов.
Реплика — субтитр: пользовательской записи голоса для неё нет.

При удержании Алекс: левая ладонь Стива под лопаткой, правая на нижней части
грудной клетки. При укладывании правая рука отпускает первой; левая направляет
спину. Последняя камера сохраняет направление и подгоняет героя к координатам
старого вступления: примерно (320, 214), высота фигуры около 28 px в 640×360.
