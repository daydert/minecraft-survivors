# Иконка вагонетки

`assets/sprites/icon_minecart.png` — оригинальная иконка предмета из локального
Minecraft Java 1.21.11, 16×16, с прозрачным фоном. Размер и палитра совпадают
с остальными ванильными предметами. Фильтрация в игре — nearest.

Восстановление из установленного клиента без сети:

```sh
python scripts/import_minecart_icon.py
```

Сборщик копирует PNG побайтно из `assets/minecraft/textures/item/minecart.png`
в клиентском JAR; поддерживает `--jar /путь/к/клиенту.jar`. Источник, SHA-256
и результат проверки прозрачности записываются в
`docs/MINECART_ICON_MANIFEST.json`. Копия файла, существовавшего перед первым
запуском: `qa/minecart_icon/icon_minecart_before.png`.

Превью на двух фонах: `qa/minecart_icon/preview.png`; увеличение только nearest.
Исходный файл уже содержал те же ванильные пиксели, поэтому форма предмета
не перерисовывалась. Сборщик закрепляет источник и воспроизводимость.

Подключение уже есть в `scripts/main.gd`: загрузка `icon_minecart` в общем
списке предметов. `scripts/ui/game_canvas.gd` рисует предмет через общий `icon`.
Боевые правила и отрисовка самой вагонетки с персонажем не меняются.
